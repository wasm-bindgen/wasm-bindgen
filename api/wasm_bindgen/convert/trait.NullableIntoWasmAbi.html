Trait NullableIntoWasmAbi 

Source 
pub trait NullableIntoWasmAbi: MaybeIntoWasmAbi {
    // Required method
    fn null() -> Self::MaybeAbi;
}
Expand description

The Null value of Nullable<Self>, which shares the ABI of Option<Self> with a second spare value beside none.

Nullable<T> and Option<Nullable<T>> take their conversions from this trait, so every T implementing it can be wrapped, including under a generic bound such as Nullable<impl JsStringLike>.

§⚠️ Unstable

This is part of the internal convert module, no stability guarantees are provided. Use at your own risk. See its documentation for more details.

Required Methods§

Source

fn null() -> Self::MaybeAbi

Returns the ABI value for Nullable::Null, which JS reads as null.

It should be guaranteed that neither into_maybe_abi nor none can produce this value.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
