Expand description

The ABI of Option<Self>.

Option<T> takes its conversion from this trait, so every T implementing it can be wrapped, including under a generic bound such as Option<impl JsNumberOrStringLike>. A type whose own ABI has a spare value for None implements OptionIntoWasmAbi instead and gets this trait from the blanket impl; a type without one, such as i32 or f64, picks a wider MaybeAbi here.

§⚠️ Unstable

This is part of the internal convert module, no stability guarantees are provided. Use at your own risk. See its documentation for more details.

It should be guaranteed that into_maybe_abi can never produce this value.

impl<T: OptionIntoWasmAbi> MaybeIntoWasmAbi for T

A spare value in T’s own ABI is the common case, so OptionIntoWasmAbi supplies the Option<T> ABI for every such type; a type without one implements MaybeIntoWasmAbi itself with a wider MaybeAbi.
