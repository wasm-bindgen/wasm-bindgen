Expand description

Marker for Rust parameter types represented by the TypeScript union number | string.

Use this trait as a bound on an experimental_generic_mono JavaScript import. Each monomorphisation retains its concrete ABI representation; this marker only restricts which Rust types may instantiate the parameter.

The union’s primitive categories use these Rust representations:

  • number: i8, u8, i16, u16, i32, u32, isize, usize, f32, f64, Number, and &Number
  • string: String, &str, JsString, and &JsString (the JsStringLike types)

This trait is experimental and may change or be removed as experimental_generic_mono evolves.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
